## Core Notes

### Overview

| Type | If-clause | Main clause | Meaning |
|---|---|---|---|
| Zero | present | present | general truth |
| First | present | will + verb | real future |
| Second | past | would + verb | unreal now/future |
| Third | past perfect | would have + pp | unreal past |

### First conditional

If it **rains** tomorrow, we **will cancel** the picnic.

### Second conditional

If I **were** rich, I **would travel** the world.

### Third conditional

If you **had told** me, I **would have helped**.

### unless / wish

- **unless** = if … not
- **wish + past** → unreal present; **wish + past perfect** → unreal past

## Worked Examples

**Ex 1.** If I ___ (be) you, I ___ (accept) it. → **were / would accept**

**Ex 2.** Fix: *If it will rain…* → **If it rains…**

**Ex 3.** I wish I ___ (can) speak French. → **could**

## Exercises

1. If you heat ice, it ___ (melt). → **melts**
2. If I ___ (have) more time, I would read more. → **had**
3. Translate: 要是明天下雨,我们就改期. → **If it rains tomorrow, we will postpone / reschedule.**
