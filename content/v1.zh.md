## 核心讲解

### 前缀:否定与程度

**前缀 (prefix)** 加在词根前面,通常改变意义但不改变词性。

否定类前缀:

- **un-** = 不/相反:happy → **un**happy;lock → **un**lock
- **in-/im-/il-/ir-** = 不:**in**correct, **im**possible, **il**legal, **ir**regular
- **dis-** = 相反/否定:agree → **dis**agree;honest → **dis**honest
- **non-** = 非:**non**-smoker, **non**-stop
- **mis-** = 错误地:**mis**understand, **mis**spell

程度与方向前缀:

| 前缀 | 义 | 例 |
|---|---|---|
| re- | 再/回 | rewrite, return |
| over- | 过度 | overwork, oversleep |
| under- | 不足 | underpaid, underestimate |
| pre- | 之前 | preview, prepay |
| co- | 共同 | cooperate, coworker |

**提示:** in- 在 m/p 前变 im-(impolite),在 l 前变 il-(illegal),在 r 前变 ir-(irresponsible)——为发音方便。

### 名词/形容词/动词后缀

**后缀 (suffix)** 加在词根后面,主要改变**词性**。

名词后缀:

- **-tion/-sion** 动作/结果:decide → deci**sion**;educate → educa**tion**
- **-ment** 动作/状态:develop → develop**ment**;agree → agree**ment**
- **-ness** 性质:happy → happi**ness**;kind → kind**ness**
- **-er/-or/-ist** 人:teach → teach**er**;act → act**or**;art → art**ist**

形容词后缀:

| 后缀 | 义 | 例 |
|---|---|---|
| -ful | 充满 | useful, careful |
| -less | 缺乏 | useless, careless |
| -able/-ible | 可…的 | comfortable, visible |
| -ous | 具…性质 | famous, dangerous |
| -al | 关于 | national, personal |

动词后缀:

- **-ize/-ise** 使…化:modern → modern**ize**;real → real**ize**
- **-ify** 使…:simple → simpl**ify**;pure → pur**ify**
- **-en** 使变…:wide → wid**en**;short → short**en**

**词性转换链:** decide (v) → decision (n) → decisive (adj) → decisively (adv)。记一条链胜过记四个孤立词。

### 复合词与合成

**复合词 (compound)** 由两个词合成新义,写法有三种:

| 写法 | 例 |
|---|---|
| 连写 | notebook, keyboard, weekend |
| 连字符 | mother-in-law, well-known |
| 分写 | bus stop, ice cream |

- 复合名词重音常在**第一个词**:*GREEN*house(温室)≠ green *HOUSE*(绿房子)。
- 复合形容词作定语常带连字符:a **well-known** writer;但作表语常不带:The writer is well known。

### 词根与同源词

**词根 (root)** 是意义核心,多来自拉丁/希腊语。认得词根就能猜一串词:

| 词根 | 义 | 派生词 |
|---|---|---|
| port | 搬运 | export, import, transport, portable |
| spect | 看 | inspect, respect, spectator |
| dict | 说 | predict, dictionary, dictate |
| vis/vid | 看 | visible, vision, video, evident |
| graph | 写/画 | photograph, biography, graphic |

**同源词 (cognate)** 指跨语言形义相近的词。对中文母语者,更要警惕**假朋友 (false friends)**——看着熟却义变了。

### 词汇笔记本方法

被动认得 ≠ 会用。建议按**词族 (word family)** 整理:

1. 一栏一个词根/词族,横向列出各词性形式。
2. 每词配一个**自己的例句**,不只抄中文。
3. 标注**搭配**(make a decision)与**语域**(正式/口语)。
4. 用间隔重复 (spaced repetition) 复习:1 天、3 天、7 天、14 天。

**避免假朋友:** 别单凭前缀硬猜。*invaluable* 不是「无价值」而是「极宝贵」;*flammable* 与 *inflammable* 都指「易燃」。遇到就查证,别想当然。

### 小结

- 前缀改义(否定/程度/方向),后缀改词性。
- 记一条词性转换链胜过记孤立单词。
- 复合词看重音与写法;词根可猜一串同源词。
- 警惕假朋友,用词族笔记 + 间隔重复巩固。

## 典型例句

**例 1.** 填空:加前缀构成反义词。

> **题目.** It is ___possible to finish this today; the deadline is ___realistic.
>
> **解.** impossible / unrealistic
> in- 在 p 前变 im-;unrealistic 用 un-。

**例 2.** 改错:

> **原句.** Her kindness and her carefulness impressed us. She spoke very confident.
>
> **解.** …She spoke very **confidently**.
> 修饰动词 spoke 要用副词:confident → confidently。

**例 3.** 翻译:

> **中文.** 这个便携设备很受欢迎,但被严重低估了。
>
> **解.** This **portable** device is popular but badly **underestimated**.
> port(搬运)→ portable;under- 表「不足」。

**例 4.** 选择:哪个后缀能把 modern 变成动词?

> **题目.** A) -ment  B) -ize  C) -ful
>
> **解.** B) -ize → modernize(使现代化)。-ment 造名词,-ful 造形容词。

**例 5.** 写作:用一个词根写三个派生词并各造一句。

> **任务.** 选 spect / port / dict 之一。
>
> **参考.** (spect) I *inspect* the report every week. I *respect* my old teacher. The *spectators* cheered loudly.

## 练习与自测

1. 加前缀构成反义词:legal, regular, honest, understand。
2. 把 develop 转成名词,把 wide 转成动词。
3. 改错:This app is very use and easy to learn.
4. 说出词根 vis/vid 的义,并写两个派生词。
5. 复合词分类:notebook, well-known, bus stop——哪个连写、连字符、分写?
6. 判断真假朋友:invaluable 是「无价值」吗?

**参考答案.**

1) illegal, irregular, dishonest, misunderstand  2) development;widen  3) This app is very **useful** and easy to learn.  4) 看:visible, video / vision / evident(任二)  5) notebook 连写;well-known 连字符;bus stop 分写  6) 不是,它意为「极宝贵」。
