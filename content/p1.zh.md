## 核心讲解

### IPA 入门

**为什么学音标:** 英语「拼写 ≠ 读音」——*through / though / tough* 里的 *ough* 读法各不相同。IPA(国际音标)一个符号只对应一个音,查词典时斜线里的 /.../ 就是它。看音标读词,比「看字母猜音」可靠得多。

- **元音(vowels):** 分短元音 /ɪ e æ ʌ ɒ ʊ ə/ 与长元音 /iː ɑː ɔː uː ɜː/。
- **辅音(consonants):** 如 /p b t d θ ð v r/ 等。
- **长音符号 ː:** 表示把元音拖长,如 /iː/(sheep)长于 /ɪ/(ship)。
- **重音符号 ˈ:** 放在重读音节前,如 *about* /əˈbaʊt/。

| 符号 | 例词 | 近似 |
|---|---|---|
| /iː/ | see, tea | 长「衣」 |
| /ɪ/ | sit, big | 短促「衣」 |
| /æ/ | cat, bad | 咧嘴的「爱」 |
| /ə/ | about, teacher | 轻声「呃」 |
| /θ/ | think, three | 咬舌清音 |

### 元音对比练习

英语元音比中文多,靠**最小对立对(minimal pairs)**训练耳朵——两词只差一个音:

| 对比 | 例 1 | 例 2 |
|---|---|---|
| /iː/ 对 /ɪ/ | sheep 绵羊 | ship 船 |
| /iː/ 对 /ɪ/ | seat 座位 | sit 坐 |
| /æ/ 对 /e/ | bad 坏 | bed 床 |
| /ʌ/ 对 /ɑː/ | cut 切 | cart 推车 |

- **schwa /ə/ 最重要:** 它是英语出现最多的音,只出现在**非重读**音节,又短又轻:*banana* /bəˈnɑːnə/ 两个 a 都读 /ə/。
- **练法:** 一对词交替读、录音回放,确认自己发出的是两个不同的音,而不是同一个。

### 辅音难点 th / v / r

- **/θ/ 与 /ð/(th):** 舌尖轻抵上齿。清音 /θ/ = *think, three, both*;浊音 /ð/ = *this, mother, breathe*。中文母语者易把 *think* 读成 *sink*、把 *this* 读成 *dis*——注意舌头要略微露出齿间。
- **/v/:** 上齿咬下唇并振动声带。区分 /v/ 与 /w/:*vest* 对 *west*;区分 /v/ 与 /f/:*very* 浊、*ferry* 清。
- **/r/:** 英语 /r/ **不卷舌打颤**,舌尖后缩但不碰上颚:*red, right, sorry*。别和 /l/ 混:*rice* 对 *lice*。
- **词尾辅音别加元音:** *book* 不读成「布克-呃」;*and* 结尾的 /d/ 轻收即可。

### 重音决定词性(noun / verb)

许多双音节词**拼写相同**,重音在前是名词,重音在后是动词:

| 词 | 名词(重音在前) | 动词(重音在后) |
|---|---|---|
| record | ˈrecord 记录 | reˈcord 录制 |
| present | ˈpresent 礼物 | preˈsent 呈现 |
| object | ˈobject 物体 | obˈject 反对 |
| increase | ˈincrease 增长 | inˈcrease 增加 |

- **规律:** 两音节词「名词/形容词多重前,动词多重后」。
- **后缀会移动重音:** *-tion / -ic / -ity* 会把重音拉到它前一个音节:*ˈphotograph → phoˈtography → photoˈgraphic*。重音读错,母语者常常听不懂。

### 节奏与 chunking

- **英语是重音节拍语言:** **实词**(名词、实义动词、形容词、副词)重读;**虚词**(冠词、介词、助动词)弱读。
- **弱读形式:** *to* → /tə/,*and* → /ən/,*of* → /əv/,*can* → /kən/。*I can GO* 里 *can* 轻;*I CAN'T go* 里 *can't* 才重。
- **意群 chunking:** 按意义把句子切成小块,在块间停顿,而不是每个词都停:*When I finish work / I'll call you.*
- **连读 linking:** 前一词的辅音与后一词的元音会连起来:*an apple* 听起来像 *a-napple*。
- **自我纠正:** 手机录一段,对照词典发音,标出读错的重音与元音,再录一次。

### 小结

- IPA 让你「查得准、读得对」,别用字母猜音。
- 元音靠最小对立对练;schwa 只出现在非重读音节。
- th / v / r 是难点:舌头位置、咬唇振动、不卷舌打颤。
- 重音位置能改变词性与词义,读错会听不懂。
- 英语讲节奏:实词重、虚词弱、按意群停顿并连读。

## 典型例句

**例 1.** 句型套用(最小对立对):

> **题目.** 用 /iː/ 与 /ɪ/ 各造一词并读出:sheep / ___。
>
> **参考.** sheep /iː/ 对 ship /ɪ/;类似 seat 对 sit、feel 对 fill。

**例 2.** 发音重音标注(名词还是动词):

> **原句.** They will ___ (record) a new song. 该读 ˈrecord 还是 reˈcord?
>
> **解.** 作动词,读 reˈcord /rɪˈkɔːd/;名词 *a ˈrecord* 才重前。

**例 3.** 流利表达改写(弱读与连读):

> **原句.** I / want / to / go / home.(逐词重读,生硬)
>
> **解.** *I wanna go home.* → *to* 弱读为 /tə/,*want to* 连读;只有实词 *go, home* 重读。

**例 4.** 迷你对话(纠 th 音):

> **任务.** 读出并注意 th 的清浊。
>
> **参考.** A: *Is this the third one?* B: *No, the other one — over there.*(this / the / other 浊 /ð/;third 清 /θ/)

**例 5.** 汇报片段(句重音):

> **任务.** 汇报一句数据,标出该重读的词。
>
> **参考.** *Sales GREW by twenty PERCENT this QUARTER.*(实词 grew / percent / quarter 重读,虚词轻带)
