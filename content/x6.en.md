## Core Notes

### Being seated & starting

- *A table for two, please.* / *Do you have anything available now, or is there a wait?*
- Server openers: *Can I start you off with something to drink?* / *Are you ready to order?*
- Need more time: *Could we get a couple more minutes?*

### Ordering

- **The go-to phrase:** *I'll have the …* / *Can I get the …?*
- **Ask about a dish:** *What comes with it?* / *Is it spicy?* / *Is the … any good?*
- **Recommendations:** *What do you recommend?* / *What's popular here?*

### Customizing

- *Can I get the dressing **on the side**?*
- *Could you make it **without** onions?* / *Is it possible to swap the fries **for** a salad?*
- *I have a **nut allergy** — does this have nuts in it?*

### For here, to go & the bill

- *For here* (eat in) vs. *to go* (takeaway) — *Can I get that **to go**?*
- *Could we get the **check** (US) / **bill** (UK), please?*
- *Are you paying together or separately?* → *We'll **split it**.* / *It's on me.*

### If something's wrong

Stay polite and indirect: *Sorry, I think there's been a **mix-up** — I ordered the chicken.* The server will *get it sorted*.

## Worked Examples

**Ex 1.** Sauce served separately: *Can I get the dressing ___ ___ ___?* → **on the side**

**Ex 2.** Ask for takeaway: *Can I get that ___ ___?* → **to go**

**Ex 3.** Ask for the bill (US): *Could we get the ___?* → **check**

## Exercises

1. Order politely: *I ___ have the grilled salmon.* → **'ll**
2. No onions: *Could you make it ___ onions?* → **without**
3. Split the bill: *We'll ___ it.* → **split**
4. Something's wrong: *I think there's been a ___.* → **mix-up**
