## Core Notes

### TEEL / PEEL structure

A strong paragraph has a top, a filling, and a base:

- **TEEL** = **T**opic + **E**xplain + **E**xample + **L**ink
- **PEEL** = **P**oint + **E**vidence + **E**xplanation + **L**ink

| Part | Job |
|---|---|
| Topic / Point | State the one main idea |
| Explain / Evidence | Say why, or give proof |
| Example | One concrete instance |
| Link | Wrap up or move on |

### Unity & coherence

- **Unity:** one paragraph = one idea; every sentence supports the topic sentence.
- **Coherence:** sentences flow via linking words, pronouns, synonyms, and old-to-new order.

### Linking words by function

| Function | Words |
|---|---|
| Addition | moreover, furthermore, also, besides |
| Contrast | however, whereas, nevertheless |
| Cause/effect | therefore, as a result, consequently |
| Example | for example, for instance, such as |
| Sequence | first, next, then, finally |
| Summary | in short, to sum up, overall |

Punctuation: *It rained; however, we went out.*

### Length & rhythm

Aim for **3–8 sentences**; mix long and short. Put the topic sentence **first** (unlike some Chinese layouts) and split separate ideas into separate paragraphs.

### Revision checklist

1. One clear topic sentence?
2. Every sentence supports it?
3. Transitions between sentences?
4. At least one concrete example?
5. A closing or linking sentence?

### Summary

Topic → explain → example → link; one idea per paragraph; connect the sentences and close cleanly.

## Worked Examples

**Example 1.** Topic sentence: *Working from home saves commuting time but demands self-discipline.*

**Example 2.** Build TEEL from *Reading is good* → state the benefit, explain it, give one example, link to a habit.

**Example 3.** Fill in: *It looked perfect. ___, it failed ___ no one tested it.* → **However / because**

**Example 4.** Order ② ④ ① ③ = topic → explain → example → link.

**Example 5.** Review: five unrelated sentences about a city lack **unity** — pick one idea and develop it.

## Exercises

1. Write a topic sentence for "the hardest part of learning English."
2. Function of *consequently*? → **cause/effect**
3. Fix: *It was raining, however we went out.* → **…raining; however, we…**
4. Expand *Exercise helps sleep* into a TEEL paragraph.
5. Where does an English topic sentence usually go? → **first**
6. A sentence about ticket prices sits in a paragraph about breakfast — do what? → **delete or move it**

**Answer key.** See items 2, 3, 5, 6; (1) and (4) self-check against the TEEL model.
