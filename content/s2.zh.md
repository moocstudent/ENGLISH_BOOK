## 核心讲解

### 条件句总览

| 类型 | 条件从句 | 主句 | 意义 |
|---|---|---|---|
| 零条件 | If + **一般现在** | **一般现在** | 普遍真理 |
| 第一条件 | If + **一般现在** | **will + 动词** | 可能发生的将来 |
| 第二条件 | If + **过去式** | **would + 动词** | 与现在/将来事实相反 |
| 第三条件 | If + **过去完成** | **would have + 过去分词** | 与过去事实相反 |

### 第一条件 (Real Future)

If it **rains** tomorrow, we **will cancel** the picnic.

- 条件有可能成真; 主句用 will / may / can / might。

### 第二条件 (Unreal Present/Future)

If I **were** rich, I **would travel** the world.

- **were** 用于所有人称(正式); 口语也常见 was。
- 表示「不太可能」或「与事实相反」。

If I **knew** her number, I **would call** her. (其实不知道)

### 第三条件 (Unreal Past)

If you **had told** me earlier, I **would have helped** you.

- 过去已无法改变,只谈假设结果。

### unless / as long as / provided that

- **unless** = if … not: Unless you hurry, you'll miss the train.
- **as long as** = 只要: You can stay as long as you keep quiet.
- **provided that** = 正式「倘若」

### wish / if only

- **wish + 过去式** → 与现在相反: I wish I **spoke** better English.
- **wish + 过去完成** → 与过去相反: I wish I **had studied** harder.

### 小结

- 第一条件:真实可能 → 现在 + will
- 第二条件:虚拟现在 → 过去 + would
- 第三条件:虚拟过去 → had done + would have done
- unless = if not; wish 后时态「后退一级」

## 典型例句

**例 1.** If I ___ (be) you, I ___ (accept) the offer.

> **解.** were / would accept — 第二条件。

**例 2.** If she ___ (study) harder, she ___ (pass) the exam last term.

> **解.** had studied / would have passed — 第三条件(上学期已过)。

**例 3.** 改错: If it will rain, we will stay home.

> **解.** If it **rains**, we will stay home. — 条件从句不用 will。

**例 4.** Unless you ___ (sign) the form, we cannot process your application.

> **解.** sign — unless = if you don't sign, 用一般现在。

**例 5.** I wish I ___ (can) speak French fluently.

> **解.** I wish I **could** speak French fluently. — wish 后 can → could。

## 练习与自测

1. If you heat ice, it ___ (melt). (零条件)
2. If I ___ (have) more time, I would read more. (第二条件)
3. If they ___ (leave) earlier, they wouldn't have missed the flight. (第三条件)
4. 翻译: 要是明天下雨,我们就改期。
5. 用 unless 改写: If you don't water the plants, they will die.

**参考答案.**

1) melts  2) had  3) had left  4) If it rains tomorrow, we will postpone it. / …we'll reschedule.  5) Unless you water the plants, they will die.
